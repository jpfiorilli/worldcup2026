# 🏆 World Cup 2026 — Live Scores

A real-time web app for the FIFA World Cup 2026 (USA · Canada · México).

🔗 **[Open the app](https://jpfiorilli.github.io/worldcup2026)**

## Features

- ⚽ **Live scores** with auto-refresh every 30 seconds
- 🗓 **Full fixture** — all 72 group stage matches across 12 groups (A–L)
- 📊 **Group standings** — live W/D/L/Pts updated in real-time
- 🕒 All times in **ART (UTC-3, Buenos Aires)**
- 📱 **iPhone-friendly** — add to Home Screen from Safari for a native feel

## Usage

Open [https://jpfiorilli.github.io/worldcup2026](https://jpfiorilli.github.io/worldcup2026) in any browser.

**On iPhone:** Safari → Share → *Add to Home Screen*

## Data source

Live scores are pulled from the ESPN public soccer API (`site.api.espn.com`). No API key required.

## Tournament

- 48 teams · 12 groups · 104 matches
- Kick-off: June 11, 2026 (México City)
- Final: July 19, 2026 (MetLife Stadium, New Jersey)
